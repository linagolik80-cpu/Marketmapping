# ГДЗ 1. Границы рынка — рынок кофе

Интерактивная карта рынка кофе для занятия по курсу «Маркетинговые стратегии».
Одна карта и семь границ рынка — по одной на каждого потребителя.

Учебный проект. Не является сайтом Drinkit или Dodo Brands.

## Как пользоваться

- Кнопки над картой или стрелки ← → — переключение границ.
- Esc — вернуться ко всей карте.
- «Своя граница» — клик по блокам собирает границу вручную.

## Как опубликовать на GitHub Pages

1. Создайте публичный репозиторий и загрузите в него все файлы из этой папки.
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

Сайт — один файл `index.html`, сборка не нужна. Шрифт Inter загружается из Google Fonts.
